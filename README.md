# Rate My Stall

A community food stall rating application with a cosy scrapbook theme. Built with React, Vite, and Vitest.

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Running Tests

Run the Vitest test suite:

```bash
npm test
```

## Linting

Check code formatting and rules:

```bash
npm run lint
```
